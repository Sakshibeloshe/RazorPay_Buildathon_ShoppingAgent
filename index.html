How the Trust Score Works
Every listing's claims are checked two ways. First, a set of deterministic checks that need no AI at all — is a return policy present, is the price stated consistently, is there real contact/business information. Second, an LLM evidence review asks whether each specific claim ("clinically tested," "certified organic," "reverses aging") is actually backed by something in the listing, or just asserted. The two scores combine into one trust_score per product, which travels with it into the structured feed — so any agent that reads the feed, not just this dashboard's, can see the same signal before deciding whether to recommend or purchase it.
